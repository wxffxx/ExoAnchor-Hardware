# ExoAnchor P4 V2.3B4 standalone project

[中文](README_zh.md)

Prepared on 2026-10-22 from local archives. This directory extracts `ESP32P4_Prototype_V2.3b4layers_260724封存（已验证）` with its schematics, PCB, and library dependencies. No current cloud-project synchronization was performed. Chinese documentation is authoritative.

The inherited schematic name is `SCH_ESP32P4_Prototype_V2.3b6_1`, but its bound board, PCB silkscreen, and four copper layers identify **V2.3b4**. The source board name says “verified”; that is a historical label, not a new physical validation performed here.

The KiCad conversion repairs SMD pads, 185 schematic/PCB component links, cross-sheet labels, source short-circuit symbols, power references, and local library defaults. It restores 16 independent native PCIe wire groups to correct V2 compatibility-export merging of GND, 3V3AUX, and WAKE#. `U12.B10` is 3V3AUX; `U12.B11` is WAKE#. Front/back R-shaped copper artwork is reconstructed from source paths with arcs sampled at a maximum step of 2 degrees. Source text, frames, and layouts remain, including existing frame overlaps.

One 0.00166624 mm F.Cu track on `P4_VDDO1_FLASH` was omitted by the V2 export and restored from its native V3 record. Both variants omit four zero-length native line records. See [track comparison](validation/native-track-comparison.json). Cross-format geometry is not claimed to be byte-identical. Native JLCEDA design documents are unchanged.

## Repeat the checks

From this directory with a compatible `kicad-cli`:

```sh
kicad-cli sch export netlist --format kicadxml -o validation/kicad-netlist.xml KiCad/ExoAnchor_P4_V2.3B4.kicad_sch
python3 scripts/verify_conversion.py
```

The script resolves its own project directory and exits nonzero on parity failure. It does not replace ERC/DRC, manufacturing review, or physical validation.
